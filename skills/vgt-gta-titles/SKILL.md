# Титры GTA 6 для VGTimes

Разбей новую фразу на четыре строки по смыслу. Третья несёт главный акцент. Используй короткие английские строки для VGTimes. Для финала подходит вопрос со смысловым ударением на третьей строке.

Запусти из папки скилла с Python, Pillow, NumPy и FFmpeg в PATH:

    python scripts/gta_titles.py "IS THIS" "THEIR IDEA OF" "ROMANCE" "IN VICE CITY?" --layout date --duration 1.8 --output hook.mov

Выбирай date для компактного блока слева, details для широкого по центру. По умолчанию генератор берёт локальные шрифты из архива Claude. На другой машине укажи --fonts с каталогом, где есть Rhythmic_RUS.otf и TT Commons Pro Trial Condensed Black.ttf.

Генератор выдаёт прозрачный полноразмерный MOV 1080×1920 при 60 кадрах/с для обеих композиций. Для запекания поверх подготовленного вертикального шота:

    ffmpeg -i shot.mp4 -i hook.mov -filter_complex "[0:v][1:v]overlay=0:0:eof_action=pass[v]" -map "[v]" -map "0:a?" -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a copy shot_titled.mp4

В CapCut используй запечённый шот на месте исходного с той же длительностью и расположением звука. Для просмотра дай MP4 на футаже. Работай экономно; для обычной смены текста достаточно проверить читаемость и положение титра в одном превью.

Текущая версия — рабочее приближение. Для дальнейшей доводки используй [референсы и тайминги](references/style.md).

## Проверка обложек Instagram Reels

Перед работой открой правила канала и утверждённую обложку этого бренда. Для мастера 1080×1920 проверь фактический экспорт в двух видах: полный кадр 9:16 с учётом интерфейса Reels и центральный кроп сетки 3:4, 1080×1440 от x=0, y=240 (видимая область по вертикали от 240 до 1680 пикселей). Для другого разрешения масштабируй координаты пропорционально. Если задано ручное кадрирование профиля, проверь и его. Граница кропа и зона интерфейса — разные проверки.

Открой уменьшенное превью кропа и проверь весь заголовок, включая последнюю строку, контуры букв, плашки, лица и смысловую деталь. Оставь видимый запас до края. В полном кадре проверь правую колонку кнопок и нижнюю подпись. Для игровых шортсов рабочий ориентир для важного текста и лиц — x=70–940, y=250–1550 при 1080×1920. Учитывай расположение элементов в эталоне конкретного формата. Результат проверки сообщай по готовому файлу с указанием проверенного кадрирования.

«Проверь сейфзоны» означает проверить существующий файл и назвать результат. Изменяй обложку, когда запрошена правка. При локальной правке используй согласованный оригинал, меняй только указанный элемент и повторяй проверку. Для другой версии бренда сохрани утверждённую композицию и проверь экспорт каждой версии отдельно.
