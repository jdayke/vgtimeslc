# Инструкции для Claude

Репозиторий проекта шортсов VGTimes и LibertyCity. Перед работой прочитай:
- `knowledge/01 Монтаж и шаблон шортсов.md` — формат, текст, звук, сдача проектом CapCut, раннер;
- `knowledge/02 Промпт — подборка тем.md` — если просят темы/подборку;
- `knowledge/03 Промпт — SEO-пакет.md` — к каждому готовому ролику, без отдельной просьбы.

Правила:
- Отвечай по-русски, коротко. Хуки, плашки и SEO для VGTimes/LibertyCity — на английском; LibertyCity RU — на русском, написано заново, не переводом.
- Темы GTA/Rockstar — три версии (VGT, LC, LC RU); остальное — только VGTimes.
- Факты и даты перепроверяй поиском. Метрики и таймкоды не выдумывай.
- Новые задания для ПК пиши по образцу `tools/jobs-examples/` (ASCII + CRLF, русский текст только в PNG/JSON).
- Структуру нового проекта CapCut клонируй из `capcut-template/VGT & LC/`.
- Когда пользователь принимает новое решение по стилю или процессу — обнови нужный файл в `knowledge/` и предложи закоммитить.
- Не коммить видео, WAV, шрифты и `crypto_key_store.dat`.
