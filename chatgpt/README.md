# VGTimes и LibertyCity — шортсы в ChatGPT

1. Создайте в ChatGPT проект «VGTimes и LibertyCity — шортсы».
2. В меню проекта откройте настройки и вставьте текст из [instructions.txt](instructions.txt) в поле инструкций.
3. Скачайте [vgt-lc-knowledge.txt](vgt-lc-knowledge.txt) и загрузите в источники проекта. Это самостоятельный текстовый файл с правилами и примерами.
4. Откройте новый чат внутри проекта и отправьте пробный запрос ниже. Для командной работы владелец может пригласить коллег через «Поделиться». Для самостоятельной копии достаточно передать два файла.

## Пробный запрос

> Есть короткий фанатский клип по Zelda со звуком автора. Нужен репост для VGTimes. Какой формат, язык и звук ты предложишь, что запросишь у меня для сборки и что укажешь при публикации?

Ответ выбирает английский репост VGTimes со светлой карточкой и звуком исходника, запрашивает клип или ссылку и контекст для хука и указания автора. Zelda относится к тематике VGTimes.

## Обновление

После изменения редакционных правил обновите соответствующий раздел файла знаний по исходному документу, указанному в заголовке раздела. Замените прежний файл в источниках проекта и повторите пробный запрос. Для работы с новым выпуском приложите его материалы в отдельном чате проекта.
